# Silver Bullet LIVE (XAUUSD, M5)
Defaults = the tested best exit style: one trade, 2R target, stop to break-even at 1R, 1% risk, sweep + FVG required.
Attach to an **XAUUSD M5** chart. Test on demo first.
Safety inputs: InpEnableTrading (kill switch), InpAllowRealAccount (must be true on real), InpDailyLossPct (default 3%),
InpAllowMinLot / InpMaxRiskPctMinLot (small accounts).

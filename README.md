# aitrading

Bullish engulfing strategy for XAUUSD (gold).

- `mt5/BullishEngulfing_XAUUSD.mq5` - MetaTrader 5 Expert Advisor (BUY only, risk-% sizing, SL under pattern low, TP at 2R)
- `python/bullish_engulfing_bot.py` - Python backtester (CSV input: time,open,high,low,close)

Test on a demo account first. No strategy is guaranteed to be profitable.

# aitrading
Strategies for MetaTrader 5 (XAUUSD). One folder per strategy under `strategies/`, each with its EA (`.mq5`) and `tester.ini`.

Run: `./run.sh <strategy>` (pull -> compile -> backtest -> open report). Quit MT5 first.
Test on demo first. No strategy is guaranteed profitable.
`python/` holds an optional standalone Python backtester.
